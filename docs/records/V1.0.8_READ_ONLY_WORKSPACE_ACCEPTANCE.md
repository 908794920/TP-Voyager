## Sensitive-path defect found and fixed by live verification

The first Windows live pass exposed a real enforcement gap that unit tests could not:

- `forbidden_paths` listed only `.git`/`.codebuddy`/`.qoder` directories and had no credential-file globs (`.env`, `*.pem`, `*.key`, private keys);
- Qoder's no-scope route used built-in `Read`/`Grep`/`Glob` against the live `cwd`, bypassing the ACP `fs/read_text_file` callback;
- CodeBuddy's `Glob`/`Grep` were authorized by search root only, so sensitive content leaked through search results.

Fix (committed on the merge line): `agent_runtime/backends/workspace_snapshot.py` materializes a sensitive-path-free workspace snapshot, and both Qoder and CodeBuddy no-scope read-only routes now run against it. See `CHANGELOG.md` v1.0.8.
