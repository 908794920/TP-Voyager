# TP-Voyager v1.0.8 Release Report

## Decision

**RELEASE BLOCKED**

The v1.0.8 implementation objectives are materially implemented and the runnable automated contract suite is green, but the final execution plan defines Windows Qoder/CodeBuddy account-live acceptance as a release-blocking gate. That environment is unavailable in this sandbox, so this report does not issue `RELEASE v1.0.8`.

## Release objective implemented

1. Normal local repository read-only no longer uses Captain-predicted `max_files` / `max_bytes` admission capacity.
2. Explicit frozen/bounded `read_scope` remains bounded and fail-closed.
3. Qoder normal read-only uses real cwd + ACP + `Read/Grep/Glob`; explicit scope still uses the existing snapshot truth path.
4. CodeBuddy normal read-only uses the existing Python SDK in workspace mode + plan mode + `Read/Glob/Grep`; explicit `context_id` preserves frozen Context behavior.
5. Patch, deterministic verification, repository research, Durable lifecycle, Artifact/Evidence, and schema boundaries were not redesigned.
6. TP-Spec-Coding AI role actions are covered by an automated composition contract.

## Qoder acceptance status

Automated ACP command/host policy is covered. The implementation constructs the normal read-only ACP client with real `cwd`, context-window passthrough, `.git/.codebuddy/.qoder` host forbidden paths, and Vendor tool visibility/allow set `Read/Grep/Glob`. Explicit bounded scope still materializes a snapshot from `routing_metadata.read_scope`.

**Windows Qoder Live Matrix: BLOCKED / NOT RUN.** No authenticated Qoder CLI is available in the current environment. Therefore Vendor-native sensitive-path behavior, real tool visibility, real write/terminal invariants, and real cancel/resume are not marked PASS.

## CodeBuddy acceptance status

Automated SDK option/callback/dispatcher tests cover workspace mode and frozen mode. Workspace read-only is configured with plan mode, `Read/Glob/Grep`, all other known built-ins disallowed, `mcp_servers={}`, `setting_sources=[]`, and TP-Voyager path/tool deny logic. Frozen mode keeps native tools disabled.

**Windows CodeBuddy Live Matrix: BLOCKED / NOT RUN.** The SDK/CLI is unavailable in the current environment. In particular, live evidence is still required to prove the effective interaction between trusted allow rules and `can_use_tool` for Vendor-native reads. `read_files` / `search_code` are intentionally not promoted into CodeBuddy `controlled_capabilities`.
